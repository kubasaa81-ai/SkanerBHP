# Skaner BHP

Aparat telefonu czyta kod kreskowy (etykieta z Programu BHP albo kod producenta),
a telefon wpisuje go w komputerze jak klawiatura Bluetooth (+ Enter).
Na komputerze nic nie trzeba instalować.

- Budowanie: GitHub Actions (zakładka Actions) -> gotowy plik w Releases: `SkanerBHP.apk`
- Telefon: Android 9 lub nowszy z Bluetooth
- Tylko jedna aplikacja może naraz udawać klawiaturę Bluetooth - zamknij inne (np. Bluetooth Keyboard & Mouse).
